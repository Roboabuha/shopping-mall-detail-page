# 쇼핑몰 상세페이지 제작 가이드

## 1. 개요
이 프로젝트는 쇼핑몰 상품 상세페이지를 빠르게 제작하기 위한 템플릿과 컴포넌트를 제공합니다.

## 2. 템플릿 사용법

### 기본 템플릿
- 위치: `templates/product-detail.html`
- 반응형 디자인 (모바일/태블릿/PC)
- 주요 섹션:
  - 이미지 갤러리 (메인 + 썸네일)
  - 상품 정보 (가격, 옵션, 구매 버튼)
  - 탭 영역 (상세/스펙/리뷰/Q&A)

### 커스터마이징 체크리스트
1. **상품 제목** 수정
2. **가격 / 할인율** 수정
3. **이미지** 교체 (Unsplash 예시 → 실제 상품 이미지)
4. **옵션** (색상/사이즈) 변경
5. **스펙 테이블** 내용 수정
6. **상세 설명** 작성
7. **브랜드/로고** 교체

## 3. 이미지 가이드
- 메인 이미지: 최소 800×800px 이상 권장
- 상세 이미지: 가로 900~1200px
- 썸네일: 200×200px
- 포맷: WebP 또는 최적화 JPEG 권장
